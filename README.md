# An Explainable Ensemble Learning Framework for Early Patient Risk Prediction in Healthcare

## Overview
A machine learning project for predicting diabetes-related health outcomes and early hospital readmission using healthcare data.

## Datasets
- **Diabetes Health Indicators:** Multiclass diabetes prediction.
- **Diabetes 130-US Hospitals:** Early hospital readmission prediction.

## Models
- Logistic Regression
- Random Forest
- Extra Trees
- Soft Voting Ensemble
- Balanced Random Forest

## Technologies
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, SHAP.

## Evaluation Metrics
Accuracy, Precision, Recall, F1-score, ROC-AUC, and Confusion Matrix.

## Project Structure
- `datasets/` — Input datasets
- `results/` — Model metrics and trained models
- `Explainable_Ensemble_Healthcare_Risk_Prediction.ipynb` — Project notebook
